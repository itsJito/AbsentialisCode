# Version 1.2 - implementation tracker

Source of the work: `instructions.md` (the 1.2 brief). The engine split is written up on its own in
`astratto/ARCHITECTURE.md`.

How to check it:
- All gates: `./gradlew.bat selftest --no-daemon` (about three minutes). The 1.2 groups alone: `ABS_SELFTEST=v12` -
  `native12 boundary12` (`tools/SelfTests12.java`), `animals12 bugs12 combat12` (`tools/SelfTests12b.java`).
- The native core on its own: `./gradlew.bat buildNative` (builds `astratto/bin/astratto.dll` and runs its 27 checks).
- Pictures: `ABS_NOVSYNC=1 ABS_SCENARIO=v12 ABS_SHOTS=<dir> ABS_SAVES=<scratch dir> ./gradlew.bat run` (about three
  minutes: the ladder and cards, the animals alive and dead, a spider's strike, a crow's flight, the guard, Developer
  Mode). Contact sheets from it are in `docs/v1.2/`.
- `ABS_NATIVE=0` runs everything with the native core switched off (as 1.1 ran).
- `ABS_SELFTEST=probe12 ABS_PROBE="x,y,z;lm_police"` prints what is at a place in the generated city (not a gate).

## State of the gates at hand-over - read this first

- **Full suite on the final build: 696 passed, 4 failed.** `ABS_SELFTEST=v12`: 29 passed, 0 failed.
- The 4 failures are **not 1.2's**. Three were run against the untouched 1.1 source (`backup/v1.1-src.tar.gz`,
  unpacked to a scratch folder) and fail there identically: "profile JSON round-trip is lossless" (a pistol's rounds
  differ after the 1.1 Capacity upgrade) and "no stair tread has a slab ... in the head room over it" for both seeds (one
  obstructed tread). The fourth, "a weapon maxes when its last attachment unlocks - max 17", was not in the groups run
  against 1.1; it is about 1.1's weapon levels and nothing in 1.2 touches them, but that is inference, not a test.
  1.1's own tracker said its full suite had never been run on its final build; these are what such a run finds.
- **Older gates changed, and why:** the three "this build is Version 1.1" gates now expect 1.2 (one of them was already
  failing in 1.1: it wanted the label to contain "1.0"). `SelfTests.guard` now lifts the twelve-block engagement rule
  before every group, the way 1.1 made it reset weapon upgrades: about fifteen AI gates from 0.5-0.9 put people thirty
  to sixty blocks from the survivor and test what follows from being seen there. The rule itself is gated by `combat12`.
- **Nobody has played 1.2.** It was checked by gates, by one scripted run with screenshots, and by the native core's
  own test program.
