# Version 0.7 - implementation tracker

Source of the work: `instructions.md` (the 0.7 brief), with `NeuralAI.md` and `Sydney.md`.
How to check it: `./gradlew.bat selftest --no-daemon -q` (all gates) or `ABS_SELFTEST=v07` (the 0.7 groups only);
scripted visual checks with `ABS_SCENARIO=<name> ABS_SHOTS=<dir> ABS_SAVES=<scratch dir> ./gradlew.bat run`.

**State of the gates at hand-over: 533 passed, 0 failed** (0.6 ended at 483). 50 are new in 0.7; about 30 older
gates were rewritten because 0.7 changed what they asserted on purpose (the raid clock, four free squadmates, the
version string, prices, the "fat" infected) - each rewritten gate says so in its own text.

## Not done, partly done, and not verified

Read this first. Nothing below is hidden in the changelog.

| Item of the brief | State |
|---|---|
| **Every interior scored 8 or better** | **Not met.** Interiors were rebuilt (ceilings, lighting, furniture shapes, shelving, finishes) and photographed before and after. My scores went from 2-5 to **6-8**: lab 8; shop, warehouse, library, bedroom 7; some rooms 6. What holds the sevens back: the inside face of an outside wall is the outside material (one voxel, one texture), and the survey camera stands in a corner so some pictures are of the nearest cupboard. 19 room types were photographed, not all 1,589 rooms; every room is covered by measurement instead (ceiling height, container runs, reachability). Photos: `docs/v0.7/interiors/`. |
| **Weapon sounds replaced** | **Not done.** The weapons already play recordings (the CC0 Free Firearm Sound Library, since 0.5), every firearm is gated as audible, and I could not audition replacements - swapping them blind risked making them worse. Say if you want them swapped anyway and from what. |
| Infected and human voices | Done, but **chosen without hearing them**: by length, pitch and file name. A wrong take is replaced by dropping a file of the same name into `assets/audio/`. |
| "Other 8/16-bit noises" | The district beds and the reload click are gone. The menu and tension music and the interface sounds are synthesised too and were left (the brief names neither; UI audio was out of bounds). |
| Sydney "overhaul" against `Sydney.md` | **Tuned, not rebuilt.** It is still the 0.6 active ragdoll: point masses and distance constraints with PD "muscles", not 17-25 rigid bodies with joint motors and a shared physics step. The fall study changed how bodies die, keep momentum and meet vehicles. A run-over was verified by gates, not photographed. |
| Purchased gun not appearing in the stash | **Not reproduced** in two scripted attempts (fresh profile; a copy of the real one). The likely cause - a new item landing above a scrolled stash view - is fixed (auto-scroll, highlight, scrollbar). |
| NPCs vanishing with many on screen | Root cause found and fixed in code (the model cache freed meshes already queued for drawing). **Not re-tested in a crowd.** |
| Performance with many NPCs | Path planning is budgeted per frame, actors are indexed by id, minds tick on staggered clocks. **No before/after frame-time measurement was taken.** |
| Texture-pack textures | None downloaded (it was permitted, not required); textures remain the game's own. |
| Verified by code and compile only - **never seen running or gated** | No shot on resume click; first-person slide hiding the body; grenade equip and arc; larger knife; side-on cover and peek; prone crawl; handgun rest pose; weapon-light model; per-gun brass and muzzle smoke; visible spray; blinking; creator rotation toggle; abandon keeps gear; corpse stripping; deploy time of day; squad kit view. The long `ABS_AUTOSHOT` tour was not re-run for 0.7. |

Judgment calls: recruits are a seventh shop rail (after Sell) rather than a sixth department; health is restored
between operations; allegiance gives one friend and no enemies; items the brief did not list were kept, not
deleted; the Bomber lost its spit to the Spewer; a room's "hall" in a home counts as lived-in for finishes.
