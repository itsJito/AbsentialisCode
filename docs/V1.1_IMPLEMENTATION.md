## State of the gates at hand-over - read this first

- **The full suite has not been run on the final build.** The last complete run was **656 passed, 0 failed**
  (1.0 ended at 628). It was made after the animals were in and *before* the police station gates, the weapon
  progression, the vehicle changes, the ledge hang, the pool/spinel/looter fixes, the body shadows, Developer
  Mode's pick-up and the version bump. A full run started after the weapon progression was killed by the host
  for lack of memory (not a test failure) and was not started again.
- The 1.1 groups were run together on the final code: **`ABS_SELFTEST=v11`: 43 passed, 0 failed.**
- So: every 1.1 gate passes; whether every *older* gate still passes with the later changes is **not known**.
  The change most likely to disturb an older gate is weapon progression (a survivor's untouched weapon now does
  about half damage). To keep the older ballistics gates about factory weapons, `SelfTests.guard` now clears the
  survivor's weapon tuning at the start of every group - that is a change to the harness and has itself only been
  exercised by the `v11` run. **Run the full suite before trusting this build.**
- Older gates changed, each saying so in its own text: the three version gates (1.1); "sixth attachment refused:
  five at most" and "swapping ... at five" (every open slot may now be used); the female "hole" gate (thighs);
  the Sydney "far bodies are passive" gate (far bodies are driven too).

**Nobody has played Version 1.1.** It was built and checked by gates and by stills from scripted runs. Nothing
that moves has been watched in motion by a person.
